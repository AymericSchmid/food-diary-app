# GenAI Disclosure

## Tools Used 

I used ChatGPT as a development assistant during this project. Because this was an assignment with a hard deadline and very short timeframe, I used GenAI more extensively than I normally would in a longer project. I used it to speed up planning and implementation.

No GenAI tool was connected directly to my code editor, and no code was automatically inserted into the project. I did not copy and paste generated code blindly. When ChatGPT suggested code or implementation ideas, I reviewed them, rewrote or adapted them to fit my project structure, and tested them in the actual application.

## How I Used It

ChatGPT helped me with:

- breaking down the requirements into smaller tasks
- discussing architecture choices
- understanding Supabase integration details
- debugging mobile browser issues 
- improving UI structure
- drafting parts of the documentation

## Manual Contributions

I manually created the project, configured Supabase and LogMeal, wrote and adapted the app code, integrated the UI components, tested the flows, fixed the bugs and deployed the app.

I also made the final product decisions, including the overall design, feature set, and user experience.

## Verification

All AI suggestions were checked through code review and testing. I verified the main flows on the local app and the deployed version.
